## Vision

### 10x Check
The 10x version of agent identity is reliability-routed, self-crediting seats: work routes to the seat with a proven track record in that skill/repo, failed landings feed the seat's own learned rules (blameless), and downstream praise (laurels) returns to the seat on wake. This foundation spec builds only the identity + track-record substrate; the 10x surface (routing, laurels, blameless learning) is the roadmap it unlocks. Persistent agent identity with an independent-eval-derived track record is genuine market white space — only Letta is a true analog.

## Accepted Scope (v1)
- SeatStore: seats + seat_events tables, get_or_create_seat (COALESCE model), get_seat, get_seat_by_name, append_event, get_track_record (SQL aggregate), rename_seat (dormant), get_seat_store() singleton.
- SeatResolver: pure seat_key + degradable resolve_seat.
- seat_hooks: record_outcome (degradable) + record_rating (Task 8).
- fleet_agents.seat_id column + create_agent param.
- Engine binding: resolve-once per step via _seat_ids cache, bind seat_id, record outcomes.
- Read endpoint: GET /api/v1/seat-track-record?skill= (read-only, keyed by skill).
- Eval-label capture: POST /api/v1/ratings → 'rating' seat_event; avg_rating in track record.
